# D10 — Sign-in is email and password only in 1.0; GitHub is a public-work link on the mentor profile
- Date, owner: 2026-10-19, Arkadiusz, confirmed at the Open Questions gate of `.ai/specs/2026-10-19-mentor-accounts-and-offer.md`
- Context and the options weighed: email + password (already specified by `engineering-standards.md`), GitHub OAuth only, or both.
- Decision and why: email + password; no new provider or dependency, and the founders invite mentors by hand. A GitHub link on the profile serves "public work shows they have done it" (Goals, N02). Origin: the agent's recommendation, accepted by the owner.
- Consequences, and what would make us revisit it: developers without a password manager may find registration slower; revisit if sign-up drop-off appears or mentors ask for GitHub login.
- Status: active
