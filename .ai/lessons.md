# Lessons learned

Short, durable findings for AI agents and humans. Newest first. Format: `- YYYY-MM-DD – lesson (context/link)`.

- 2026-10-24 – Base UI checkboxes do not toggle when the hidden input or a label is clicked in browser tests: click the element with `role="checkbox"` (or `box.click()` in page script) and check `aria-checked` before saving. Verify the saved value in the database, not only the page text (Epic 01 phase 4 manual test).

- 2026-10-24 – `instanceof` on core errors fails in Next.js dev: the cached container and a route handler can load the same error class from two module graphs, so a rule error (e.g. slot 24 h lead time) became a 500. `apiHandler` now recognises AppError by shape (status and code); regression test in `apiHandler.test.ts`. Do not rely on `instanceof` for errors that cross module boundaries.

- 2026-10-19 – Never run `git stash` (or any command that hides or discards local changes) in an agent run, not even to compare with HEAD – use `git show HEAD:<file>` or `git diff`. A stray stash hid the whole uncommitted stage-1 work until `git stash pop` (review rule R3: never destroy local state; `.ai/runs/2026-10-19-lesson-6-design-system.md`).
- 2026-10-19 – `cn` (tailwind-merge semantics) does not know custom Tailwind utilities: `cn("gap-2", "gap-in-group")` keeps both. Register design-system spacing/type classes in `createCn` (`packages/ui/src/lib/utils.ts`), and name type roles `type-*`, not `text-*`, so they never collide with colour classes.
- 2026-10-19 – Measure contrast of translucent tokens composited over their surface: dark `--border` is white 10%, and painting it alone on a transparent canvas reads as pure white (17:1 instead of 1.25:1) (`packages/ui/.storybook/blocks/Foundations.tsx`).
- 2026-10-19 – A multi-package `npm install -D -w @devmentor/ui …` with Storybook crashed npm 10 (ERESOLVE on `react-dom`, then `Cannot read properties of null (reading 'edgesOut')`). Declaring the `react-dom` peer and installing the packages one at a time worked with the same versions.
- 2026-10-14 – Never run `docker compose down -v` (or anything else that deletes a developer's local data) to verify a change – use temporary resources or ask first. It wiped the local dev database while verifying PR #14; now enforced by review rule R3 (`.ai/skills/om-code-review`).
- 2026-10-13 – agent-browser does not support Playwright pseudo-selectors like `:has-text()`. Use semantic locators (`find role button click --name …`) and give repeated controls unique accessible names.
- 2026-10-13 – Integration tests start their own `next dev`; use `NEXT_DIST_DIR=.next-test` so they don't collide with a developer's running dev server.
- 2026-10-13 – Vitest 5: with `--project <name>` coverage `include` globs are resolved relative to that project's root, without it relative to the repo root. Check coverage with a plain `npm run test:coverage`, not a filtered run.
- 2026-10-13 – Vitest's diff printer reads arbitrary keys of compared objects; services injected with Awilix PROXY mode (strict) then throw "Could not resolve 'size'". Compare such objects by reference (`a === b`).
- 2026-10-13 – shadcn `Spinner` has `role="status"`; inside another status region it creates a duplicate live region. Make it decorative there.
- 2026-10-13 – Next.js passes no `params` to handlers of routes without dynamic segments – treat the route context as optional (`apiHandler`).
- 2026-10-13 – Zod 4: `z.email()` is a string *format*, not a `ZodString` instance – detect it via `.format === "email"` (`CrudForm`).
- 2026-10-13 – Client components must not import package roots that reach MikroORM (`@devmentor/core`, `@devmentor/db`) except with `import type`; use the client-safe subpaths `@devmentor/core/validators/*` and `@devmentor/db/constants`.
- 2026-10-13 – MikroORM generates a table rename (`tableName` change) as drop + create – data loss. Always read generated migrations; rewrite renames as `alter table ... rename` (`packages/db/src/migrations/Migration20261013124642.ts`).
- 2026-10-13 – The MikroORM migration snapshot file is named after the database (`.snapshot-<dbname>.json`). Running the CLI against another DB name creates a stray snapshot – delete it, never commit it.
- 2026-10-13 – Tailwind 4 only scans the app package by default; classes used in `@devmentor/ui` need `@source` in `globals.css`, otherwise ui components render unstyled.
- 2026-10-13 – `@next/env` `loadEnvConfig` caches the first load; calling it again for another dir is a no-op. Use `process.loadEnvFile` for the root `.env` (`packages/db/src/config.ts`).
- 2026-10-13 – In this monorepo `next dev` writes its managed AGENTS block to `packages/app/AGENTS.md`, not the root one.
- 2026-10-13 – shadcn init (Tailwind 4) can write `--font-sans: var(--font-sans)` in `@theme inline` – a self-reference that silently drops the custom font. Check `globals.css` after running shadcn.
- 2026-10-13 – MikroORM 7 packages `@mikro-orm/sql`/`@mikro-orm/postgresql` are not in Next.js' default server externals; keep them in `serverExternalPackages`.
- 2026-10-13 – `LayoutProps` / `PageProps` are generated by Next.js into `.next/types`; on a clean checkout (CI) `tsc` fails without them. Always typecheck via `npm run typecheck` (runs `next typegen` first). (PR #3)
- 2026-10-13 – Route handlers that hit the database must call `await connection()` from `next/server` first, so they run at request time instead of being prerendered at build (Cache Components). (`app/api/health/route.ts`)
- 2026-10-13 – Library choices follow the course stack (MikroORM, Awilix, shadcn/ui, monorepo). Check `AGENTS.md` before adding a dependency for a concern the stack already covers.
- 2026-10-19 – `cn` treats `type-*` roles as conflicting with font-size/weight/**family**, so a class like `font-sans` placed *before* `type-meta` is silently dropped – put family/weight overrides after the role. Base UI checkbox/radio/switch render `<span role=…>`: style disabled with `data-disabled:`, not `disabled:`, and never use ids with spaces (the label link breaks; axe reports `aria-toggle-field-name`).
- **2026-10-20 – Intl zone names differ between Node/ICU versions.** `formatUtcOffset` parsed `timeZoneName: "longOffset"` and treated `"GMT"` as zero; CI's Node 22 returns `"GMT+00:00"`, so the test passed locally and failed in CI (`UTC+0` vs `UTC`). Compute offsets arithmetically from the wall-clock parts (`formatToParts` → `Date.UTC` − instant) instead of parsing Intl's display names; never assert on Intl display strings that are not pinned by the spec.
- **2026-10-20 – Flaky focus assertions in Storybook play functions.** `BookingForm › Field Error From Server` passed on the PR and failed once on `main`: the test asserted `toHaveFocus()` right after a mocked server error, while focus moves in a later render. Any focus that moves after an async step (server response, mount effect) must be awaited: `await waitFor(() => expect(el).toHaveFocus())`. Focus moved synchronously by `userEvent.tab()` can stay a direct assertion.
- **2026-10-23 – Entity schemas must be singletons across Next.js module graphs.** Next evaluates `@devmentor/db` in several graphs (RSC, SSR, route handlers) while the ORM is cached on `globalThis`, so a query from another graph passes a different schema object and `populate` fails with `TypeError ... reading 'filter'` in `EntityLoader`. Create every entity with `defineSingletonEntity` (`packages/db/src/entities/define.ts`), and write relations as a whole-property thunk (`user: () => p.oneToOne(User)`), never `p.oneToOne(() => User)` (`Entity '' was not discovered`).
- **2026-10-26 – Stale browser sessions break integration runs.** agent-browser keeps cookies under the session name, and the test sessions had fixed names. A run interrupted with ^C left a sign-in for a user that the next run's fresh database did not have, so `SiteHeader` threw on every page and the sign-in form never rendered (7 failing UI tests). `Browser` now adds a random suffix per instance. Also: `notFound()` inside `<Suspense>` answers 200 (the stream has started); look records up before the boundary so the status is 404. Match errors by `name` across Next's module graphs (as `isNotFound` does), not with `instanceof`.
- 2026-10-27 — **When a hand-written and a generated migration add the same columns, keep only the generated one.** A fresh database runs both in order, so the second `alter table … add column` fails with `column already exists` and `db:migrate` in the integration global setup aborts before any test runs. The generated file and its regenerated `.snapshot-devmentor.json` are the pair to keep; delete the hand-written one in the same commit.
- 2026-10-27 — **A downloaded course snapshot is a different repository state: compare it against a checklist, never copy it over.** Its notes listed three traps (double booking across session lengths, a relation before its column, the session cookie after a role grant); each was checked in this repository before anything else was touched. In this sandbox, `git worktree add -b` and `git branch -f` fail on writing `.git/config` for upstream tracking; pass `--no-track`.
