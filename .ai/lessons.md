# Lessons learned

Short, durable findings for AI agents and humans. Newest first. Format: `- YYYY-MM-DD – lesson (context/link)`.

- 2026-10-13 – `LayoutProps` / `PageProps` are generated by Next.js into `.next/types`; on a clean checkout (CI) `tsc` fails without them. Always typecheck via `npm run typecheck` (runs `next typegen` first). (PR #3)
- 2026-10-13 – Route handlers that hit the database must call `await connection()` from `next/server` first, so they run at request time instead of being prerendered at build (Cache Components). (`app/api/health/route.ts`)
- 2026-10-13 – Library choices follow the course stack (MikroORM, Awilix, shadcn/ui, monorepo). Check `AGENTS.md` before adding a dependency for a concern the stack already covers.
