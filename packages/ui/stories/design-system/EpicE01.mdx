# E01 – Mentor offer: slots, prices, share link

Backlog #21 with stories #25–#28, specified in `2026-10-19-mentor-accounts-and-offer.md`. A senior engineer is invited by the founders, registers, sets prices for 25- and 50-minute text sessions, publishes slots, and shares a link – optionally also appearing on a public list.

## Flow

| Step | Screen | What the person does | Components | State map |
|---|---|---|---|---|
| 1 | `/admin/invitations` | An admin invites a mentor by email; the link is shown once | `CrudForm`, `InvitationLinkPanel`, `CopyField`, `InvitationStatusBadge`, `DataTable` | [Screens](?path=/docs/product-e01-screens-state-map--docs) |
| 2 | `/register/mentor?token=` | The mentor registers from the invitation | `CrudForm`, `Alert` | same |
| 3 | `/login`, `/register` | Anyone signs in or registers | `CrudForm`, `AccountMenu` | same |
| 4 | `/mentor` | Sees what stands between them and being bookable | `OfferChecklist`, `PendingBookingsNotice` (E02) | same |
| 5 | `/mentor/profile` | Writes the profile, sets both prices, opts in to the public list | `MentorProfileForm`, `PriceList` | same |
| 6 | `/mentor/slots` | Adds slots in their own zone, deletes open ones | `AddSlotForm`, `SlotTimeField`, `SlotList`, `DeleteSlotDialog` | same |
| 7 | `/mentors` | A visitor browses the public list, filters by stack | `MentorCard`, `ActiveFilters`, `ResultCount`, `Pagination` | same |
| 8 | `/m/[slug]` | A visitor opens a mentor by link: profile, prices, bookable times | `MentorProfileHeader`, `PriceList`, `TagList`, `PublicWorkLinks`, `SlotList` | same |

## Decisions that shape the screens

| Decision | Effect |
|---|---|
| D13: a slot is bookable from 24 h ahead | `SlotList` says "Not bookable – starts too soon"; the server decides (`bookable`, Q9) |
| R08, D03: public list is opt-in, the share link always works | `/mentor` checklist explains why a mentor is not listed |
| N02: no ratings | `MentorCard` shows public-work links and stack tags instead |
| C6: dense rows, no avatar wall | `MentorCard` is a list row |
| Time zones | every time shows its zone; DST handled in `SlotTimeField` ([pattern](?path=/docs/patterns-time-with-zone-and-dst--docs)) |
