# Components

Every component that exists in `packages/ui`, grouped by the job it does, each with a small working preview, one sentence on what it is for and a link to its documentation page. The previews are the components' own stories (`Playground`, or the first state story), not copies. For imports and for when not to use a component, see [Start here](?path=/docs/design-system-start-here--docs); to choose between neighbours, see [How to choose](?path=/docs/design-system-how-to-choose--docs).

Where the pages live in the menu: **Primitives** (shadcn/ui base-nova on Base UI, adapted to our tokens), **Primitives / Panel blocks** (building blocks of pages: forms, tables, feedback, layout), **Product / E01** and **Product / E02** (components of one domain, named after the epic that needs them). Dialogs and menus open from their trigger in the preview. Previews that call the API (a submit) have no server in this page – open the component's page or story to try those.
