# MentorProfileForm

`import { MentorProfileForm, type MentorProfile, type MentorProfileInput } from "@devmentor/ui/components/mentors/MentorProfileForm"`

Product component, concept `mentors` (E01, #25, #28). Follows the [Form pattern](?path=/docs/patterns-form--docs); price fields follow [Amount in PLN](?path=/docs/patterns-amount-in-pln--docs).

## 1. Purpose

Lets a mentor say who they are, what they charge and whether they want to be listed – everything a mentee sees before booking.

## 2. When to use

| Situation in DevMentor | Source |
|---|---|
| `/mentor/profile` | spec E01, Phase 2 (profile, prices) and Phase 4 (list toggle) |

## 3. When not to use

| Instead of `MentorProfileForm`… | Use | Why |
|---|---|---|
| Simple admin forms | `CrudForm` | this form exists because `CrudForm` cannot infer tags, a link list, prices or a list of links (C7) |
| Publishing times | `AddSlotForm` (batch 4) | different resource |

## 4. Anatomy

Form-level error (after a failed save); **Profile**: name, headline, bio (optional, character count), stack (checkboxes, optional), public work (up to 5 link fields, *Add link*, *Remove link n*); **Prices**: 25- and 50-minute fields with the currency, both may stay empty; **Visibility**: *Show me on the public list* (checkbox); *Save profile* + saved status.

## 5. Variants

None.

## 7. Behaviour and accessibility

| Rule | Source |
|---|---|
| Labels visible; groups (`Stack`, `Public work`, `Prices`, `Visibility`) are fieldsets with legends. | WCAG 1.3.1, 3.3.2 |
| Changed fields are checked on blur; errors clear as they are fixed; focus goes to the first error after submit. | Form pattern; C20 |
| *Add link* moves focus to the new field; at five links a sentence replaces it (no silently disabled button). | B17; WCAG 2.4.3 |
| Repeated *Remove link n* buttons have unique names. | WCAG 2.4.6 |
| "Profile saved." in a polite status, only after the server confirms; focus moves to it so keyboard and screen-reader users know the save worked. | S10; prompt stage 3; G12 |

## 8. Content

Limits from spec E01: headline ≤ 120, bio ≤ 2,000 (plain text), ≤ 5 https links, prices PLN 10–10,000 (sanity bounds). Name and headline (1–120 characters) required, bio, stack and links optional (spec E01, Q8; C44). Listing depends only on prices and a bookable time. Price input accepts "180", "180.5", "180,50" (C41, **proposal**). Hint under the prices: a change applies only to new bookings (spec E01, Grill Me).
