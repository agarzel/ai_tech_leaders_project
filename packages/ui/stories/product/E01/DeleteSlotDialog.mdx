# DeleteSlotDialog

`import { DeleteSlotDialog } from "@devmentor/ui/components/availability/DeleteSlotDialog"`

Product component, concept `availability` (E01, #27). The instance of the pattern [Delete confirmation](?path=/docs/patterns-delete-confirmation--docs), built on [AlertDialog](?path=/docs/primitives-alertdialog--docs).

## 1. Purpose

Asks before a slot is deleted, shows what the server answered, and tells the page when it is done.

## 2. When to use

| Situation in DevMentor | Source |
|---|---|
| *Delete* on an open slot in `/mentor/slots` | spec E01, Edge Cases (Deleting a slot) |

## 3. When not to use

| Instead of `DeleteSlotDialog`… | Use | Why |
|---|---|---|
| A booked slot | no action; the booking is cancelled instead | spec E01: booked → `conflict` "Cancel the booking instead" (R04, #34) |
| Anything undoable at once | no dialog | a slot can be added again, but mentees may already look at it |

## 4. Anatomy

Trigger (*Delete* in the row), title naming the slot, one sentence of consequence with the zone, an error alert when the server refuses, *Keep slot* and *Delete slot*.

## 5. Variants

None.

## 7. Behaviour and accessibility

| Rule | Source |
|---|---|
| Focus starts on *Keep slot*, the safe choice. | B51, WAI-ARIA alertdialog |
| While the request runs both buttons are disabled and Escape does nothing. | one submit at a time |
| A refusal stays inside the dialog, in words; the person can still back out. | C58 |
| The trigger's name includes the time (*Delete the slot on Thu 22 Oct, 18:00*). | `AGENTS.md` (unique names) |
| After `onDeleted` the page moves focus – the row that had it is gone. | WCAG 2.4.3 |

## 8. Content

Title: "Delete the slot on {time}?" Buttons are verbs with the object: *Keep slot*, *Delete slot*. Consequence: "Mentees can no longer book this time (zone). You can add it again later."
