# E01 screens – state map

Each screen state has its own full-screen story (C14). Screens are compositions of package components; the pages themselves are app code. Batch 2 covers sign-in and admin; the mentor screens follow in batches 3–4.

## /login (spec E01, Phase 1)

| State | Story |
|---|---|
| Form | [Default](?path=/story/product-e01-screens-login--default) |
| Wrong email or password (generic message) | [InvalidCredentials](?path=/story/product-e01-screens-login--invalid-credentials) |
| Too many attempts (429) | [RateLimited](?path=/story/product-e01-screens-login--rate-limited) |
| No network | [NetworkError](?path=/story/product-e01-screens-login--network-error) |
| Signed in | [Success](?path=/story/product-e01-screens-login--success) |
| 320 px | [Narrow320](?path=/story/product-e01-screens-login--narrow-320) |
