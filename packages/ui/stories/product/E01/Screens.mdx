# E01 screens – state map

Each screen state has its own full-screen story (C14). Screens are compositions of package components; the pages themselves are app code. Batches 2–4 cover sign-in, admin, the mentor overview, profile, slots and the public pages.

| No network | [NetworkError](?path=/story/product-e01-screens-login--network-error) |
