# AddSlotForm

`import { AddSlotForm } from "@devmentor/ui/components/availability/AddSlotForm"`

Product component, concept `availability` (E01, #27). Instance of the patterns [Form](?path=/docs/patterns-form--docs) and [Time with zone and DST](?path=/docs/patterns-time-with-zone-and-dst--docs). A bespoke form: `CrudForm` has no date-time field that knows zones (AGENTS.md: say why).

## 1. Purpose

Lets a mentor publish one more time mentees can book.

## 2. When to use

| Situation in DevMentor | Source |
|---|---|
| Above the list on `/mentor/slots` | spec E01, Phase 3 |

## 3. When not to use

| Instead of `AddSlotForm`… | Use | Why |
|---|---|---|
| Adding many slots at once | not built | spec E01 has one slot per request |
| Editing a slot | delete and add again | slots have no edit in spec E01 |

## 4. Anatomy

`SlotTimeField` (date, time, zone, preview, error), *Add slot*, a status line ("Slot added."), and an alert above for errors that belong to no field.

## 5. Variants

None.

## 7. Behaviour and accessibility

| Rule | Source |
|---|---|
| "Added" only after the server confirms (201). | Form pattern |
| Values are kept after an error; one submit at a time. | Form pattern |
| Server rules (24 h, 60 days, 15-minute grid, 50-minute spacing) are shown at the field in the server's words; the form does not re-check them. | C55, spec E01 (Slot rules) |
| Errors without a field (`conflict`, network) appear above the form. | Form pattern |
| Focus goes to the date after an error and after success. | WCAG 2.4.3 |
| The confirmation is in a polite status region, not a toast. | S10 |

## 8. Content

Button *Add slot*, busy *Adding…*, confirmation *Slot added.*, error title *Could not add the slot*. The word is *slot* in mentor screens, as in the navigation.
