# BookingQuestion

`import { BookingQuestion } from "@devmentor/ui/components/bookings/BookingQuestion"`

Product component, concept `bookings` (E02, #30, #32). Pulled forward from batch 6: `/bookings/[id]` shows the question.

## 1. Purpose

Shows a booking's question as the mentee wrote it.

## 2. When to use

| Situation in DevMentor | Source |
|---|---|
| `/bookings/[id]` | spec E02, UI/UX |
| `/mentor/bookings` (batch 6) | spec E02, UI/UX |

## 3. When not to use

| Instead of `BookingQuestion`… | Use | Why |
|---|---|---|
| Markdown or code blocks | not built | plain text only (Q5); a future session spec may add code blocks |

## 4. Anatomy

One paragraph of body text with the line breaks kept.

## 5. Variants

None; a collapsed form for rows may follow in batch 6.

## 7. Behaviour and accessibility

| Rule | Source |
|---|---|
| Rendered as text; markup is never interpreted. | security (spec E02: the question may hold code) |
| Long words and URLs wrap. | WCAG 1.4.10 |

## 8. Content

Exactly the mentee's words. Never in a title, an error or a log.
