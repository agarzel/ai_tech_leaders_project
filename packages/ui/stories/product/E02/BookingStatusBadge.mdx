# BookingStatusBadge

`import { BookingStatusBadge } from "@devmentor/ui/components/bookings/BookingStatusBadge"`

Product component, concept `bookings` (E02, #30, #32).

## 1. Purpose

Names a booking's state in one short phrase in a row.

## 2. When to use

| Situation in DevMentor | Source |
|---|---|
| Rows of `/bookings` and `/mentor/bookings` (batch 6) | spec E02, UI/UX |

## 3. When not to use

| Instead of `BookingStatusBadge`… | Use | Why |
|---|---|---|
| The full status with the next action | `BookingStatusPanel` | a row needs a phrase, a page needs a sentence |

## 4. Anatomy

A `Badge`: *Awaiting payment*, *Awaiting mentor*, *Confirmed*, *Declined · refund on its way / refunded / refund delayed*, *Expired · …*, *Payment not completed*.

## 5. Variants

*Confirmed* is `secondary`; the rest `outline`. Never the accent (T10).

## 7. Behaviour and accessibility

| Rule | Source |
|---|---|
| The state is words, not colour. | WCAG 1.4.1 |
| The refund phase comes from the payment status, so a row never says "refunded" before the money is back. | spec E02 (Refund lifecycle) |

## 8. Content

Wording from `bookingStatusLabel`; the long form for a page is `describeBooking`.
