# BookingRow

`import { BookingRow } from "@devmentor/ui/components/bookings/BookingRow"`

Product component, concept `bookings` (E02, #30). A dense list row, like `MentorCard`.

## 1. Purpose

Shows one of the mentee's bookings in a list, with its status in words.

## 2. When to use

| Situation in DevMentor | Source |
|---|---|
| Each row of `/bookings` | spec E02, UI/UX |

## 3. When not to use

| Instead of `BookingRow`… | Use | Why |
|---|---|---|
| The mentor's list | `MentorBookingRow` | different data and actions |
| The full status | `BookingStatusPanel` | a row needs a phrase |

## 4. Anatomy

Title: mentor name and length, as the row link. One metadata line: time, zone, price. The status badge on the right.

## 5. Variants

None.
