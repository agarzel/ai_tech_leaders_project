# BookingSummary

`import { BookingSummary } from "@devmentor/ui/components/bookings/BookingSummary"`

Product component, concept `bookings` (E02, #30).

## 1. Purpose

Shows what is being bought before paying, and again on the booking page: mentor, time with zone, length, price.

## 2. When to use

| Situation in DevMentor | Source |
|---|---|
| `/book/[slotId]` above the question | spec E02, UI/UX |
| `/bookings/[id]` under the status | spec E02, UI/UX |

## 3. When not to use

| Instead of `BookingSummary`… | Use | Why |
|---|---|---|
| A list row of bookings | `BookingRow` (batch 6) | one line per booking |
| Computing a price | never | the server computes and stores it (spec E02) |

## 4. Anatomy

A description list: *Mentor*, *When* (time, zone label), *Length*, *Price* (tabular figures).

None.

## 7. Behaviour and accessibility

| Rule | Source |
|---|---|
| A `dl` pairs each term with its value. | WCAG 1.3.1 |
| The zone is named next to the time. | spec E01 (Edge Cases) |
| Long values wrap. | WCAG 1.4.10 |

## 8. Content

Terms are plain nouns. Time as everywhere: "Wed 4 Nov, 18:00 (Europe/Warsaw, UTC+1)".
