# QuestionField

`import { QuestionField, QUESTION_MAX } from "@devmentor/ui/components/bookings/QuestionField"`

Product component, concept `bookings` (E02, #30). Built on `Field` and `Textarea`.

## 1. Purpose

Collects the question the mentor will read before deciding.

## 2. When to use

| Situation in DevMentor | Source |
|---|---|
| `/book/[slotId]` | spec E02, UI/UX |

## 3. When not to use

| Instead of `QuestionField`… | Use | Why |
|---|---|---|
| A short single-line value | `Input` in a `Field` | this is a long free text |
| Editing a question after booking | not possible | the question is frozen once booked (spec E02) |

## 4. Anatomy

Label *Your question*, textarea (8 rows), hint with the limit and the count, a silent live region for the characters left, error.

## 5. Variants

None.

## 7. Behaviour and accessibility

| Rule | Source |
|---|---|
| The limit never cuts the text: a pasted question stays whole and the field says by how much it is over. | C64, WCAG 3.3.1 |
| The count is in the hint; only the last 200 characters are announced (`role="status"`). | S10 |
| Hint and error are linked with `aria-describedby`. | WCAG 1.3.1 |
| Plain text; paste code as text. | Q5, spec E02 |

## 8. Content

"The mentor reads this before deciding. Plain text, up to 2,000 characters (n used)." Error: "Shorten the question by 40 characters." and "Write your question for the mentor."
