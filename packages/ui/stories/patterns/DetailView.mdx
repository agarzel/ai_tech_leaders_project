# Detail view

A page about one thing the person owns: the status and next action above the fold, the facts below, the long text last. Instance: `/bookings/[id]`.

<Canvas of={Stories.Declined} />

## Rules

| Rule | Source |
|---|---|
| Order: status and next action (`BookingStatusPanel`), details (`BookingSummary`), then free text (`BookingQuestion`). | R01.5, P5 |
| Loading is a skeleton in the page's shape; an error says what happened with *Try again*. | C3 |
| Not found and no access are one message that does not reveal whether the item exists. | spec E02 (API) |
| Long free text wraps and keeps its line breaks; it never widens the page. | WCAG 1.4.10, Q5 |
| The page title names the other party ("Booking with Marek Zieliński"); the question never appears in a title. | spec E02 (sensitive data) |
| Statuses that change while the page is open are re-checked (payment) and say so. | C67 |
