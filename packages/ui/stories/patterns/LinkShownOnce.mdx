# Link shown once

A secret link – today the mentor invitation – is created on the server and returned in one response only; it is never stored in readable form (spec E01, Data Model: only the token's hash). The interface must make sure the person copies it before it disappears.

<Canvas of={PanelStories.Playground} />

## Rules

| Rule | Source |
|---|---|
| Show the link right after the request succeeds, in place of the form, with a copy button. | spec E01, UI/UX |
| Say plainly that it is shown only once, how long it works and who sends it. | spec E01; D11, D15 |
| Move focus to the link. | WCAG 2.4.3 |
| Confirm copying in words next to the field – no toast. When the clipboard is refused, select the text and say how to copy it. | S10; `CopyField` |
| *Done* drops the link from memory; it is never put in the URL, storage or logs. | spec E01 (Sensitive data) |
| Waiting and errors stay in the form that creates the link. | pattern Form |
| A lost link is recovered by creating a new one: inviting the same email again revokes the pending invitation, and the list shows it as *Revoked*. | spec E01 (Q6, owner 2026-10-20) |
