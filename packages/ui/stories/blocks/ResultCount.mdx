# ResultCount

`import { ResultCount } from "@devmentor/ui/backend/filters/ResultCount"`

Panel block (C9), concept-agnostic. Used by [List with filters](?path=/docs/patterns-list-with-filters--docs).

## 1. Purpose

Says how many items a list holds, and announces the new number when a filter changes it.

## 2. When to use

| Situation in DevMentor | Source |
|---|---|
| Above the mentor list | spec E01 (`Page.total`) |
| Above the bookings list (E02) | spec E02 |

## 3. When not to use

| Instead of `ResultCount`… | Use | Why |
|---|---|---|
| Counting things as a badge or a hype number | never | P10, A05 |
| Pagination's range | `Pagination` | "11–20 of 25" is about the page |

## 4. Anatomy

One line of metadata text in a polite status region: "12 mentors".

## 5. Variants

None. `noun` and an optional `plural`.

## 7. Behaviour and accessibility

| Rule | Source |
|---|---|
| `role="status"`: the new count is read after a filter changes. | WAI-ARIA status |
| Empty while loading, so an old number is never announced. | S10 |
| Metadata size, tabular figures, muted. | P2, T12 |

## 8. Content

"1 mentor", "12 mentors", "0 mentors". Count and noun only; no "found", no exclamation.

## 9. Responsive

One line of text; it wraps with the page.

<Canvas of={Stories.LargeTotal} />

## 10. API

| Prop | Type | Default | Description |
|---|---|---|---|
| `total` | `number` | – | matches across all pages (`Page.total`) |
| `noun` | `string` | – | singular |
| `plural` | `string` | `noun + "s"` | irregular plural |
| `isLoading` | `boolean` | `false` | leaves the count empty |

<Controls of={Stories.Playground} />

## 11. Code

<Source dark code={`<ResultCount total={data.total} noun="mentor" isLoading={isLoading} />`} />

## 12. Do and don't

| Do | Don't |
|---|---|
| Keep it one quiet line. | A big number or a badge. |
| Leave it empty while loading. | Show the previous count. |
