# NativeSelect

`import { NativeSelect, NativeSelectOption, NativeSelectOptGroup } from "@devmentor/ui/components/ui/native-select"`

## 1. Purpose

Lets a person pick one value from a known list – a session length, a time zone, a stack tag – using the browser's own list, which works the same with mouse, keyboard, touch and screen readers.

## 2. When to use

| Situation in DevMentor | Source |
|---|---|
| Filtering mentors by stack tag (TypeScript, React, Python, AI agents) | mentor-accounts spec, S12 |
| Choosing a role or status in admin forms (`CrudForm` renders `z.enum` as a select) | `packages/ui/AGENTS.md` |
| Time zone or session length when more than about 5 options or when space is tight | **proposal** |
| A filter or setting inside a dense row, e.g. rows per page (`size="sm"`) | B2, answer 2.1 |

## 3. When not to use

| Instead of a select… | Use | Why |
|---|---|---|
| 2–4 options that are worth comparing (25 or 50 min with prices) | `RadioGroup` | all options and prices visible at once (R01.5/P5) |
| Searching a long list | combobox – not in 1.0 (S12, "What is missing") | – |
| Several values (tags) | `Checkbox` group | a native multi-select is hard to use |
| An action menu (*Edit*, *Delete*) | dropdown menu (batch 4) | a select holds a value, a menu runs actions |

## 4. Anatomy

| Part | Optional | Notes |
|---|---|---|
| Wrapper | no | receives `className` (width) |
| `<select>` | no | `h-control`, 1 px `border-input`, 12 px padding (B8) |
| Chevron icon | no | `muted-foreground`, `aria-hidden` |
| Options / option groups | no / yes | on the `popover` surface (B7); the open list is drawn by the browser |
| Placeholder option | yes | `value=""` + `disabled`: *Choose a length* |

## 5. Variants

Size `default` (32 px, 40 px on touch) for forms; `sm` (28 px, 40 px on touch) only inside dense rows. No other variants.

## 7. Behaviour and accessibility

| Rule | Source |
|---|---|
| Native `<select>`: role *combobox*; arrow keys change the value, Space/Alt+↓ opens the list, type-ahead jumps to an option. | HTML, WAI-ARIA |
| Label with `htmlFor` on the `<select>` id (the id is passed through to the select, not the wrapper). | WCAG 1.3.1 |
| Do not submit or navigate on `change`: keyboard users change the value with arrow keys. | WCAG 3.2.2 |
| Hint and error via `aria-describedby`; `aria-invalid` when invalid. | WCAG 3.3.1 |

## 8. Content

- Options: short, parallel, sentence case; add the one fact that decides (*50 minutes · PLN 220.00*). (R01.5/P5; price format F6, temporary)
- Placeholder option says the action: *Choose a length*, not *Select…*. (**proposal**)
- The closed select cuts long option text – keep options under about 40 characters. (**proposal**)

## 10. API

`NativeSelect` takes all `<select>` props (`value`, `defaultValue`, `onChange`, `disabled`, `required`, `aria-*`) except the HTML `size`, plus:

| Prop | Type | Default | Description |
|---|---|---|---|
| `size` | `"default" \| "sm"` | `"default"` | `sm` only in dense rows. |
| `className` | `string` | – | Applied to the wrapper; width only. |

`NativeSelectOption` and `NativeSelectOptGroup` take all `<option>` / `<optgroup>` props.

## 13. Related

- **Confused with:** radio group (few comparable options), dropdown menu (actions), combobox (search, not in 1.0).
- **Used in:** `CrudForm` (`z.enum`); patterns *List with filters*, *Time with zone (DST)* (stage 3).
