# RadioGroup

`import { RadioGroup, RadioGroupItem } from "@devmentor/ui/components/ui/radio-group"`

## 1. Purpose

Lets a person choose exactly one of a few options while seeing all of them – and what each one costs – at once.

## 2. When to use

| Situation in DevMentor | Source |
|---|---|
| Session length: *25 minutes · PLN 120.00* or *50 minutes · PLN 220.00*, before the question box | R01, R01.5/P5 (price before writing), booking spec |
| Any 2–5 options worth comparing side by side | WAI-ARIA radio group |

## 3. When not to use

| Instead of radios… | Use | Why |
|---|---|---|
| More than about 5 options, or a long list (time zone) | `NativeSelect` | the list would push the form down (**proposal**) |
| Several answers | `Checkbox` group | radios allow one |
| A single on/off | `Switch` or `Checkbox` | one radio cannot be turned off |
| Switching views (*Upcoming / Past*) | tabs (batch 4) | navigation, not a form value |

## 4. Anatomy

| Part | Optional | Notes |
|---|---|---|
| `FieldSet` + `FieldLegend` | no | the question (*Session length*) |

## 7. Behaviour and accessibility

| Rule | Source |
|---|---|
| The group is one tab stop; arrow keys move and select; Space selects the focused option. | WAI-ARIA radio group pattern |
| Give a default when one option is the usual choice (25 min); otherwise leave none selected and validate on submit. | **proposal** |
| `FieldLegend` names the group; each option has its own label (`htmlFor` → item `id`, no spaces). | WCAG 1.3.1 |
| Do not submit or navigate when the value changes. | WCAG 3.2.2 |
| Hints are linked with `aria-describedby` on the item. | WCAG 1.3.1 |

## 8. Content

- Legend: the question as a noun phrase (*Session length*).
- Options: parallel, short, with the deciding fact (*50 minutes · PLN 220.00*); price format F6 (temporary).
- Hints: one line about when to pick it (*A question with code to walk through.*) (**proposal**)

## 10. API

`RadioGroup` (Base UI `RadioGroup`): `value`, `defaultValue`, `onValueChange(value, details)`, `name`, `disabled`, `required`. `RadioGroupItem` (Base UI `Radio.Root`): `value` (required), `disabled`, `id`, `aria-*`.

| Prop | On | Type | Default | Description |
|---|---|---|---|---|
| `defaultValue` | group | `unknown` | – | Initially selected value. |
| `onValueChange` | group | `(value, details) => void` | – | Called when the selection changes. |
| `value` | item | `unknown` | – | The value this option sets. |
