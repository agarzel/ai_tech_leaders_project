# InputGroup

`import { InputGroup, InputGroupAddon, InputGroupButton, InputGroupInput, InputGroupText, InputGroupTextarea } from "@devmentor/ui/components/ui/input-group"`

## 1. Purpose

Attaches a unit, an icon or a small action to a field, so the person sees what the value means (PLN) or can act on it (copy) without looking elsewhere.

## 2. When to use

| Situation in DevMentor | Addon | Source |
|---|---|---|
| The share link and the invitation link, shown with a copy button | `InputGroupButton` at `inline-end` | mentor-accounts spec (share link, invitations "shown once with a copy button") |
| Prices with the currency after the number | `InputGroupText` *PLN* at `inline-end` | D12 |
| The booking question with a character counter below | `InputGroupTextarea` + `block-end` text (`QuestionField`, stage 3) | booking spec |
| A filter field with a search icon | icon at `inline-start` | **proposal** |

## 3. When not to use

| Instead of an input group… | Use | Why |
|---|---|---|
| A plain field | `Input` | no extra frame logic |
| A field and its submit button (*Add slot*) | `Input` + `Button` next to each other | the button acts on the whole form, not on the field |
| Explaining the field | `FieldDescription` | addons are for units and in-field actions, not sentences |

## 4. Anatomy

| Part | Optional | Notes |
|---|---|---|
| `InputGroup` | no | carries the field frame: `h-control` (48 px on touch when it holds a button, B31), `border-input`, `rounded-lg`, focus and error rings (P4, T3, T4) |
| `InputGroupInput` / `InputGroupTextarea` | no | borderless field inside |
| `InputGroupAddon` | yes | `align`: `inline-start`, `inline-end`, `block-start`, `block-end`; clicking it focuses the field |
| `InputGroupText` | yes | unit or counter, `type-body`, `muted-foreground` |
| `InputGroupButton` | yes | `ghost` by default; sizes `icon-sm` (default) and `sm` (B30) |

## 5. Variants

No visual variants; the addon `align` places parts (shown below). Button sizes: `icon-sm` for an icon with `aria-label`, `sm` for a short text action.

## 7. Behaviour and accessibility

| Rule | Source |
|---|---|
| The group is `role="group"`; the label belongs to the input (`FieldLabel htmlFor` → `InputGroupInput id`). | WCAG 1.3.1 |
| An icon-only button needs `aria-label` (*Copy share link*). After copying, say so in visible text near the field (e.g. the hint changes to *Copied*), not only with an icon change. | WCAG 4.1.2, 4.1.3 (**proposal** for the copy feedback) |
| A unit (*PLN*) is not part of the accessible name; put it in the label if it matters: *Price for 25 minutes (PLN)*. | WCAG 2.5.3 |
| Touch: a group with a button grows to 48 px so the button keeps 40 px; without a button it stays 40 px. | B31, P4, WCAG 2.5.8 |

## 8. Content

- Units are short and uppercase codes as in the product (*PLN*); counters as *74 / 2,000* with `tabular-nums`. (P2, F6)
- Button text in a group: one verb, at most two words (*Copy link*). (**proposal**)

## 9. Responsive

| Width | Behaviour |
|---|---|
| 320 px | Full width; long values scroll inside the input; the addon never wraps below. |
| 768 px and 1440 px | Width of the form column; short values (price) may be narrower. |

## 10. API

| Component | Props | Notes |
|---|---|---|
| `InputGroup` | `<div>` props | frame |
| `InputGroupAddon` | `<div>` props + `align?: "inline-start" \| "inline-end" \| "block-start" \| "block-end"` (default `inline-start`) | click focuses the field |
| `InputGroupButton` | `Button` props without `size`/`type` + `size?: "sm" \| "icon-sm"` (default `icon-sm`), `type` (default `"button"`), `variant` (default `"ghost"`) | |
| `InputGroupText` | `<span>` props | unit, counter |
| `InputGroupInput` / `InputGroupTextarea` | `Input` / `Textarea` props | |

## 13. Related

- **Confused with:** `Input` + `Button` (form submit), `FieldDescription` (explanations).
- **Used in:** share link panel (`InvitationLinkPanel`), price fields, `QuestionField`; patterns *Link shown once (copy)*, *Amount in PLN* (stage 3).
