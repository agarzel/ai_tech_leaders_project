# Kbd

`import { Kbd, KbdGroup } from "@devmentor/ui/components/ui/kbd"`

## 1. Purpose

Shows which key to press, so a person learns a shortcut – like sending a message with Enter – without reading a manual.

## 2. When to use

| Situation in DevMentor | Source |
|---|---|
| The hint under the session composer: *Enter to send · Shift + Enter for a new line* | R02.2 |
| Shortcut hints in tooltips and menus (batch 4) | **proposal** |

## 3. When not to use

| Instead of Kbd… | Use | Why |
|---|---|---|
| Code, file names, versions (`values.yaml`, `1.28`) | `type-code` (Geist Mono) | R01.2/P2: monospace only for code |
| A button that looks like a key | `Button` | Kbd is text, not a control |
| Decoration, badges, tags | badge (batch 3) | – |

## 4. Anatomy

| Part | Optional | Notes |
|---|---|---|
| `Kbd` | no | `<kbd>`, `type-meta` in Geist (sans – keys are not code, R01.2), `muted` fill, `rounded-md` (B3), 20 px high |
| `KbdGroup` | yes | keys of one combination with `+` between them |

## 5. Variants

None (rule 6).

## 6. States

<Canvas of={KbdStories.States} />

Kbd is static text: default only. Hover, focus, pressed, disabled, loading, selected and error do not apply. Inside a tooltip (batch 4) it switches to the tooltip's colours (`in-data-[slot=tooltip-content]`, base-nova).

## 7. Behaviour and accessibility

| Rule | Source |
|---|---|
| Native `<kbd>`: read as text in the sentence; never focusable, never clickable. | HTML |
| Use the key's name (*Enter*, *Shift*), not a symbol only (⏎, ⇧). | WCAG 1.1.1 (**proposal**) |
| `muted-foreground` on `muted`: 7.01 : 1 (light). | tokeny.md, WCAG 1.4.3 |

## 8. Content

- Key names in English with a capital letter: *Enter*, *Shift*, *Esc*, *Tab*. (**proposal**)
- Combination: `Shift` + `Enter` with a visible plus.
- Inside a sentence, keep the sentence short: *Enter to send*.

## 9. Responsive

| Width | Behaviour |
|---|---|
| 320 px | The sentence wraps between words; a key never breaks inside. |
| 768 px and 1440 px | One line. Touch-only devices may hide keyboard hints (**proposal**). |
