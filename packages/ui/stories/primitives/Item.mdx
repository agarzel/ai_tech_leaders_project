# Item (dense list row)

`import { ItemGroup, Item, ItemMedia, ItemContent, ItemTitle, ItemLink, ItemDescription, ItemActions } from "@devmentor/ui/components/ui/item"`

## 1. Purpose

Shows many things of one kind – bookings, slots, invitations – as short rows, so a person can scan dozens of them without scrolling and open the one that needs attention.

## 2. When to use

| Situation in DevMentor | Source |
|---|---|
| Mentor's bookings (`/mentor/bookings`): question as the title, mentee, local time with zone, length and price as the metadata line, status and *Accept* | R01.1, booking spec, S21 |
| Mentee's bookings (`/bookings`) | booking spec |
| Mentor's slots (`/mentor/slots`), grouped by day | mentor-accounts spec |
| Admin invitations (pending / used / expired) when not tabular | mentor-accounts spec |

## 3. When not to use

| Instead of rows… | Use | Why |
|---|---|---|
| Admin data with many comparable columns | `DataTable` | S21 |
| One topic with a title and a form | `Card` | a panel, not a list |
| Cards per item with shadows | rows in one frame | R01.3/P3 |
| The session conversation | message groups (product component) | K1, K4 |

## 4. Anatomy

| Part | Optional | Notes |
|---|---|---|
| `ItemGroup` | no | the list: `role="list"`, one 1 px frame, 1 px lines between rows, `card` surface (R01.3, B35) |
| `Item` | no | a row: `role="listitem"`, padding `py-list-row` / `px-list-row` (8 / 12 px, T9) |
| `ItemMedia` | yes | an icon (`variant="icon"`, 16 px, `muted-foreground`) |
| `ItemContent` | no | title + metadata, no gap (T12) |
| `ItemTitle` | no | `type-label` (14 px / 500, T12), one line, ellipsis |
| `ItemLink` | when the row opens a page | inside `ItemTitle`; covers the whole row (B36) |
| `ItemDescription` | yes | the one metadata line: `type-meta` (12 px), `muted-foreground`, one line (R01.1, T12) |
| `ItemActions` | yes | status badge and at most one or two `sm` buttons; stays clickable above the row link |

## 5. Variants

None (B35): the base-nova variants (`outline`, `muted`), sizes (`sm`, `xs`), `ItemHeader`, `ItemFooter`, `ItemSeparator` and image media were not taken – one row style for every list (R01.1, rule 6).

## 6. States

<Canvas of={ItemStories.States} />

| State | Looks | Source |
|---|---|---|
| Default | `card` surface, line below | R01.3 |
| Hover (linked row) | row `muted`, title underlined | P4 (`muted` = row hover) |
| Focus (linked row) | inset neutral ring around the whole row | T4, WCAG 2.4.7 |
| Selected, pressed, disabled | not used; a row that cannot be opened has no link | rule 6 |
| Loading, empty, error of the list | skeleton rows, `EmptyState`, `ErrorMessage` (stage 3 patterns) | prompt stage 3 |

## 7. Behaviour and accessibility

| Rule | Source |
|---|---|
| `ItemGroup` is a list and each `Item` a list item; screen readers announce "list, 3 items". | WCAG 1.3.1 |
| A clickable row is one link (the title) stretched over the row – not a `div` with `onClick`, not a row wrapped in `<a>` (that would break the list and nest buttons in a link). | WAI-ARIA, B36 |
| Tab order: row link, then the row's actions. Enter opens the row. | WCAG 2.4.3 |
| Status in words (`Badge`), not colour. | WCAG 1.4.1 |
| Row actions have unique names when repeated (*Accept booking from Jan Nowak* via `aria-label` when the visible text is the same in every row). | WCAG 2.4.6, `AGENTS.md` (integration tests) |

## 8. Content

- Title: the most specific thing – the question for bookings, date and time for slots. One line; cut with an ellipsis, full text on the detail page. (R01.1)
- Metadata line: who · when (local time with zone) · length · price, separated by ` · `. (R01.1, mentor-accounts spec: time with zone label)
- No counters, no ratings, no "years of experience". (A03, A05, P10)

## 9. Responsive

| Width | Behaviour |
|---|---|
| 320 px | Title and metadata truncate; status and actions stay at the end; the row link still covers the row. |
| 768 px | Same; more text fits. |
| 1440 px | List at most `max-w-5xl` (F2); dozens of rows visible (R01.1). |

## 10. API

|---|---|---|

| `ItemContent`, `ItemTitle`, `ItemActions` | `<div>` props | |

| `ItemDescription` | `<p>` props | |
