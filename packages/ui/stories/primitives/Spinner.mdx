# Spinner

`import { Spinner } from "@devmentor/ui/components/ui/spinner"`

## 1. Purpose

Shows that a short action is in progress – saving a form, accepting a booking – right where the person is looking, until it finishes.

## 2. When to use

| Situation in DevMentor | Source |
|---|---|
| Inside a button while a form submits (*Saving…*, B18) | prompt stage 4 ("the spinner only inside a button or a short status") |
| A short, page-level wait with no known shape (`LoadingMessage`) | prompt stage 4 |

## 3. When not to use

| Instead of a spinner… | Use | Why |
|---|---|---|
| A list or panel whose shape is already known | `Skeleton` | keeps the layout from jumping (prompt stage 4) |
| A "journey" progress bar | nothing | A02 (no gamified progress) |
| A long background job | a status written in words, updated when it changes | a spinner promises "soon"; do not use it for minutes-long waits |

## 4. Anatomy

One part: `Loader2Icon` (lucide), `role="status"`, `aria-label="Loading"`, spinning continuously.

## 5. Variants

None (rule 6). Size via `className` (`size-4` default, `size-5` standalone).

## 6. States

<Canvas of={SpinnerStories.States} />

One state: spinning, always. A spinner is not disabled, focused, pressed or in error – it disappears when the wait ends, replaced by the result or an `Alert`.

**Motion exception:** unlike other components, the spin continues under `prefers-reduced-motion` – it is essential information (that something is in progress), not decoration (WCAG 2.3.3 exempts essential motion). (**proposal**, follows F3)

## 7. Behaviour and accessibility

| Rule | Source |
|---|---|
| `role="status"` announces "Loading" once when it appears. | WAI-ARIA status role |
| Next to a visible status text (*Saving…*, `LoadingMessage`'s label), the spinner must not announce itself a second time: `aria-hidden="true"` and drop `aria-label`. | `LoadingMessage` source, WCAG 1.3.1 |
| Only one live region per wait – nesting two `role="status"` elements announces the same thing twice. | `AGENTS.md` ("Watch for duplicate live regions") |

<Canvas of={SpinnerStories.ShortStatus} />

## 8. Content

No text of its own. The label describing the action lives next to it (*Saving…*, *Accepting…*), in the `-ing` form (B18).

## 9. Responsive

Same size at every width; inside a full-width button on narrow screens it keeps its 16 px size next to the label.

<Canvas of={SpinnerStories.Narrow} />

## 10. API

All props of `Loader2Icon` (an SVG): `className` (size), `aria-label`, `role`.

## 12. Do and don't

<Unstyled>
  <DoDont
    doExample={<div className="flex items-center gap-2"><Spinner aria-hidden="true" /><span>Saving…</span></div>}
    doText="One visible label; the spinner is hidden from screen readers so it is not announced twice."
    dontExample={<div className="flex items-center gap-2" role="status" aria-label="Loading"><Spinner /><span role="status">Saving…</span></div>}
    dontText="Two live regions for one wait announce the same thing twice (AGENTS.md)."
  />
</Unstyled>

## 13. Related

- **Confused with:** `Skeleton` (known shape, longer wait), `LoadingMessage` (the page-level wrapper that already combines a spinner and text).
- **Used in:** `LoadingMessage`, `CrudForm` submit, `DataTable` pagination, any button with B18's loading state.
